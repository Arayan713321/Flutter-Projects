## 🏗️ Getting Started

To run any of these projects:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Arayan713321/Flutter-Projects.git
    ```
2.  **Navigate to a project folder**:
    ```bash
    cd flodo_task_manager
    ```
3.  **Install dependencies**:
    ```bash
    flutter pub get
    ```
4.  **Run the app**:
    ```bash
    flutter run
    ```
